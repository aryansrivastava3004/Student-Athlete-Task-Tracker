# Student-Athlete Task Tracker 🏋️‍♂️📚

A lightweight, Python-based Command Line Interface (CLI) application designed to help student-athletes balance rigorous academic schedules with strict fitness and nutritional goals.

This project was developed as the **"Bring Your Own Project" (BYOP)** capstone for the **CSE0001 Digital Literacy course** at Vellore Institute of Technology (VIT) Bhopal.

---

## 🎯 The Problem

Balancing a heavy engineering course load (like preparing for calculus and discrete math exams) alongside a 6-day bodybuilding split and high-calorie nutritional tracking requires serious organization. 

Standard to-do lists often mix academic deadlines with gym routines, making it difficult to prioritize tasks effectively.

---

## 💡 The Solution

This tracker allows users to categorize their daily tasks into three distinct buckets:

1. **Academic**: Coursework, exam preparation, and coding projects  
2. **Fitness**: Workout routines and recovery days  
3. **Nutrition**: Meal planning and calorie/macro tracking  

By running entirely in the terminal, it provides a distraction-free environment to quickly log, view, and complete tasks without unnecessary complexity. 

All data is stored locally, ensuring progress is saved between sessions.

---

## ✨ Features

- **Interactive CLI Menu** – Simple and user-friendly terminal interface  
- **Smart Categorization** – Organize tasks into Academic, Fitness, and Nutrition  
- **Persistent Storage** – Saves data in `athlete_tasks.json`  
- **Status Tracking** – Clearly mark tasks as pending `[ ]` or completed `[X]`
